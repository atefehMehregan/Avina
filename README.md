# آوینا — فروشگاه آنلاین محصولات زیبایی

یک فروشگاه اینترنتی راست‌به‌چپ و فارسی برای محصولات مراقبت پوست، آرایش، مو و
بدن. تمام صفحه با HTML، CSS و جاوااسکریپت خالص ساخته شده است؛ بدون فریم‌ورک،
بدون مرحله build و بدون وابستگی خارجی جز فونت.

---

## اجرای پروژه

فایل `index.html` را باز کنید. همین. چیزی برای نصب وجود ندارد.

برای اجرا با وب‌سرور محلی (توصیه‌شده، چون `localStorage` روی `file://` در
بعضی مرورگرها خاموش است):

```bash
python3 -m http.server 8000
```

سپس <http://localhost:8000> را باز کنید.

چطور، و `main.js` جایی است که همه‌چیز شروع می‌شود.

## امکانات

| بخش | کارکرد |
|---|---|
| جستجو | زنده، با هر کلید؛ روی نام، برند، دسته و توضیح محصول |
| فیلتر | بر اساس دسته‌بندی و نیاز پوستی |
| مرتب‌سازی | ارزان‌ترین، گران‌ترین، محبوب‌ترین، بیشترین تخفیف |
| سبد خرید | افزودن، کم و زیاد کردن تعداد، حذف، خالی کردن، کشوی کناری |
| فاکتور | جمع کالاها، سود خرید، هزینه ارسال (رایگان بالای ۱٫۵ میلیون تومان) |
| علاقه‌مندی | افزودن و حذف، شمارنده هدر، نمایش فهرست |
| نگاه سریع | مودال مشخصات محصول بدون خروج از صفحه |
| شمارش معکوس | تا پایان پیشنهاد ویژه، ماندگار بین بازدیدها |
| منوی موبایل | کشویی با بخش‌های بازشونده |
| اعتبارسنجی | فرم خبرنامه با پیام خطای فارسی |
| اعلان‌ها | پیام کوتاه گوشه صفحه پس از هر عمل |

**دسترس‌پذیری:** کلید Escape پنجره‌ها را می‌بندد، کلید Tab از داخل مودال بیرون
نمی‌رود، فوکوس پس از بستن برمی‌گردد، همه دکمه‌ها `button` واقعی‌اند و برچسب
دارند، و حالت فوکوس همیشه دیده می‌شود.

**ماندگاری:** سبد خرید، علاقه‌مندی‌ها و ترتیب مرتب‌سازی در `localStorage` ذخیره
می‌شوند. اگر مرورگر این حافظه را خاموش کرده باشد سایت باز هم کار می‌کند، فقط
بین بازدیدها چیزی به یاد نمی‌آورد.

## تغییر محتوا

همه‌چیز در `JS/data.js` است؛ لازم نیست HTML را دست بزنید.

**افزودن محصول** — یک بلوک را کپی کنید و مقادیر را عوض کنید:

```js
{ id: 'p25', name: 'نام محصول', brand: 'lumiere', category: 'skincare',
  image: 'IMG/products/serum-vitc.svg', price: 690000, oldPrice: 850000,
  rating: 4.5, reviews: 120, volume: '۳۰ میلی‌لیتر',
  concerns: ['dry'], tags: ['new'], short: 'یک خط توضیح کوتاه.' }
```

`oldPrice` را `null` بگذارید تا محصول بدون تخفیف باشد؛ درصد تخفیف خودکار حساب
می‌شود. `tags` می‌تواند `new` یا `bestseller` باشد.

**تغییر دسته‌ها، برندها، مقاله‌ها، منوها و متن پیشنهاد ویژه** — فهرست‌های
`CATEGORIES`، `BRANDS`، `POSTS`، `NAV_MENU`، `FOOTER_MENUS` و `OFFER`.

**جایگزینی تصاویر** — فایل‌های داخل `IMG/` تصویرهای موقت SVG هستند. عکس واقعی را
با همان نام جایگزین کنید، یا مسیر تازه را در `data.js` بنویسید. نسبت تصویر
محصول ۱:۱ و تصویر دسته ۳:۴ است.

## آنچه به سرور نیاز دارد

این بخش‌ها عمدا شبیه‌سازی نشده‌اند، چون انجام واقعی‌شان بدون سرور ممکن نیست:

| امکان | چرا | چه چیزی لازم است |
|---|---|---|
| ثبت سفارش و پرداخت | مبلغ و موجودی باید سمت سرور بررسی شود | `POST /api/orders` و درگاه بانکی |
| ورود و حساب کاربری | بررسی رمز در مرورگر قابل دستکاری است و هیچ امنیتی ندارد | `POST /api/login` و نشست کاربر |
| عضویت در خبرنامه | ذخیره ایمیل | `POST /api/newsletter` |
| موجودی لحظه‌ای انبار | داده‌ها ثابت‌اند | `GET /api/products` |
| دیدگاه مشتریان | امتیازها نمونه‌اند | `GET/POST /api/reviews` |

فرم‌ها ورودی کاربر را **واقعا اعتبارسنجی می‌کنند**؛ فقط مرحله ارسال به سرور
وجود ندارد و صفحه صادقانه همین را می‌گوید.

هنگام اتصال به API، جای تغییر `JS/data.js` است: فهرست‌های ثابت را با `fetch`
عوض کنید و همان توابع render را صدا بزنید. بقیه فایل‌ها دست‌نخورده می‌مانند.
